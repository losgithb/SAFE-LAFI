# SAFE-LAFI

SAFE-LAFI removes ocular artifacts from multi-channel EEG by estimating the
residual contamination field and subtracting it from the recorded signals.

You can train the model directly using python train.py.

The training data and testing data can be obtained from:
[Semi-simulated EEG/EOG dataset](https://data.mendeley.com/datasets/wb6yvr725d/1).
